# CarbonPie 微信原生原型

这是与 Expo 主应用独立的微信 WXML/WXSS/JS 实现。当前13个页面入口包含记录、科普、家园、农场、资料与指南等；使用本机 wx 存储。原工作树未提交页面与 wx-login 函数已保留。

在微信开发者工具导入本目录。project.config.json 使用 touristappid，占位基础库版本沿用原工程；真实平台能力需要自己的 AppID、域名与授权。本轮未用真实账号登录开发者工具，未宣称微信编译/真机通过。根目录 npm test 中的微信测试使用隔离 wx 存储夹具，并验证离线模式不发网络或定位请求。

默认 utils/config.js 的 offlineDemo=true、云端URL/anonKey为空。公开数据为本机使用者新建的记录，未附带真实用户记录。开云前必须独立验收后端身份会话、RLS/权限、数据迁移与隐私。wx-login 当前返回身份数据但未完成客户端可用的认证会话闭环，不能用于生产。

AI页是本地指南，不是远程模型；农场和碳币仅虚拟游戏。估算系数与Expo不同，见根 docs/methodology.md。图标为新增几何图；不加载未经清权的远程照片。不附带项目私人配置、原AppID或真实联系人。
