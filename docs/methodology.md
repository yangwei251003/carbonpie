# 估算的适用边界

主应用电力参数使用2024年全国电力平均碳足迹因子0.5777 kg CO₂e/kWh，[官方公告](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202510/t20251024_1130734.html)，[官方解读](https://www.mee.gov.cn/ywdt/zbft/202510/t20251024_1130763.shtml)。它是平均碳足迹因子，不是对每位用户的实时测量。交通相对单人汽油车的简化差值、饮食、空调节电及设备待机参数是项目原型假设，缺少逐项核验资料的地方应继续完善，不作为专业认证结论。

Expo 步行/骑行相对汽油车0.2 kg/人km基准，公交本身0.045、地铁0.035，结果为差值；单次最多计入50km，当日80km。自带杯和美德默认不计kg。微信独立表使用公交0.09、地铁0.08、骑行0.18、步行0.12等直接原型系数；它们不是同一计量协议，不能汇总比较。微信碳币只是游戏奖励，不是真实资产。

新增检查拒绝非有限值/异常当日用量进入估算，微信非法数量/类型不落库也不发虚拟奖励。限制异常输入并不验证这些参数科学准确；未来需研究来源、适用地区、时间与不确定区间，再统一版本。
